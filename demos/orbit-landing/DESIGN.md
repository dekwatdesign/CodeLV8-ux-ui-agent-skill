# Orbit landing demo

Primary user: Thai creative and product teams evaluating a shared work tool. This is an assumed audience, not user research.

Flow: value proposition → fictional product preview → features → interactive workspace → illustrative pricing → local demo form.

Direction: warm ivory, violet typography and action, subtle mint/lavender aurora, restrained glass only on the floating product annotation. One semantic theme in styles.css; mobile base with wider layouts added at 600px and 980px. Native dialog and details retain keyboard semantics. Reduced motion removes transitions and smooth scrolling.

All project data, plans, dates and prices are fictional. No server, account, payment, storage, or telemetry. The form validates locally, preserves values on error, inserts user text with textContent, and clears on close. Escape closes the dialog and focus returns to the opener. Board/list and monthly/yearly controls update their pressed states.

Fonts reuse the repository's original LINE Seed Sans TH Regular/Bold WOFF2 assets at ../pms-dashboard/assets/fonts/ with its OFL.txt attribution. Keep the sibling font folder when moving this demo.

Open index.html directly, or serve the repository over localhost with an existing static server. No dependencies or build step needed for the page itself.

Scope: only additive files in demos/orbit-landing. Existing pending repository changes preserved. The repository has no matching project entry in the canonical Project Registry; no guessed graph identity or knowledge-base changes made.
